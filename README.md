# Mystical Agriculture — Resource Farming Mod

[![Download Latest](https://img.shields.io/github/v/release/serpentbytechisel/mystical-agriculture-farming-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/serpentbytechisel/mystical-agriculture-farming-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Grow every ore, material, and even mob drops as crops using magical Essence Seeds.

![Mystical Agriculture — Resource Farming Mod Preview](https://cdn.modrinth.com/data/C95ReXie/images/905df0baa810e976e55a013eff7c9ddcec104328_350.webp)

## Features

- Essence Seeds for every ore including diamonds and Netherite
- Grow mob drops: blaze rods, wither skulls, dragon eggs
- Inferium to Supremium essence tier upgrades
- Soulium Soil for mob essence crop growth
- Fully compatible with Garden Cloches and auto-farmers

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
